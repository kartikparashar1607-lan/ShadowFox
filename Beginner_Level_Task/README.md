\# Data Visualization - Matplotlib \& Seaborn



\## 📌 Task Description



This project explores data visualization techniques using two popular Python libraries: \*\*Matplotlib\*\* and \*\*Seaborn\*\*. The goal was to understand how to create effective, insightful visualizations from data.



\## 📂 Files



\- `Data\_Visualization\_Matplotlib.pdf` - Visualization work done using Matplotlib

\- `Data\_Visualization\_Seaborn.pdf` - Visualization work done using Seaborn



\## 🛠️ Tools Used



\- Python

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



\## 🎯 Key Learnings



\- Creating various types of plots (line, bar, scatter, histograms, etc.)

\- Customizing plots for better readability

\- Comparing Matplotlib's low-level control with Seaborn's high-level statistical plotting
