\# Advanced Level Task – Student Performance Dashboard



\## 📌 Project Overview

Is project mein 1500+ students ka performance data analyze kiya gaya hai. Dataset mein study hours, sleep hours, social media usage, attendance, stress level, parental education, part-time job jaise factors shamil hain jo exam score par asar dalte hain.



\## 📊 Dataset

File: student\_performance.csv



Columns:

\- student\_id, age, gender

\- study\_hours\_per\_day, sleep\_hours\_per\_day, social\_media\_hours\_per\_day

\- attendance\_pct

\- part\_time\_job, extracurricular, tutoring

\- parental\_education, internet\_access

\- stress\_level, previous\_score, exam\_score



\## 🛠️ Tech Stack

\- Python (Pandas, Numpy) – Data analysis (Student\_Performance\_Analysis.ipynb)

\- HTML + Chart.js – Interactive dashboard visuals

\- Streamlit – App deployment/hosting
